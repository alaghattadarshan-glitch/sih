# Smart India Hackathon Demo & Delivery Guide

## SIH26168 — AI-ML based Intelligent Dead Reckoning System

### Demo Overview

This document outlines the demonstration workflow and presentation plan for the Smart India Hackathon grand finale evaluation.

### Planned Modules for Demonstration

1. **Live/Simulated Sensor Stream Ingestion**: Real-time display of high-rate IMU and GNSS data streams.
2. **GNSS Outage Simulation**: On-the-fly toggling of GNSS signal loss to demonstrate Dead Reckoning capability.
3. **Trajectory Visualization**: Comparative display showing:
   - Raw INS (Uncorrected Drift)
   - GNSS Reference Ground Truth
   - AI-ML Intelligent Dead Reckoning Solution
4. **Metrics Dashboard**: Real-time RMSE calculation during outages.

> [!NOTE]
> Demonstration pipeline will be connected once core algorithms and dashboard components are implemented.
